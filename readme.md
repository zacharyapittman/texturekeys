
# TextureKeys

A focused ambient texture instrument.

Blend looping samples with keyboard, MIDI sustain, touchscreen Hold, or Latch.

## Philosophy

Keep it simple. Make it sound good. Make it reliable.

TextureKeys is not a synthesizer or DAW. It is designed to blend ambient audio textures without pitch-following or note retriggering.
